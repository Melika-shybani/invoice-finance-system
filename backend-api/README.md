# سامانه مدیریت مالی، حسابداری و صورتحساب الکترونیکی کسب‌وکار (Backend API)

بخش بک‌اند سامانه جامع مدیریت مالی، حسابداری دوبل، صدور فاکتور و صورتحساب الکترونیکی سامانه مودیان مالیاتی، توسعه‌یافته با **Node.js**، **Express.js** و پایگاه داده **MongoDB (Mongoose)**.

---

## 🌟 ویژگی‌ها و امکانات اصلی

### ۱. مدیریت کاربران و تعیین سطح دسترسی (RBAC)
- **سه سطح دسترسی استاندارد:**
  - `admin` (مدیر سیستم): دسترسی نامحدود به تمامی بخش‌ها و تعریف کاربران و تنظیمات.
  - `accountant` (حسابدار): دسترسی به طرف‌های حساب، کالاها، فاکتورها، دریافت‌ها و پرداخت‌ها، صندوق و بانک، اسناد حسابداری، اعتبارسنجی و ارسال فاکتور، گزارش‌های مالی و دفاتر روزنامه و کل.
  - `sales` (کاربر فروش): دسترسی به ثبت/مشاهده مشتریان، کالاها، و پیش‌نویس صورتحساب‌های فروش.
- احراز هویت امن با توکن **JWT** و هش کلمات عبور با **bcrypt**.

### ۲. تعریف مشتریان و تأمین‌کنندگان (Parties)
- مشخصات کامل هویتی، نام، نوع (مشتری، تأمین‌کننده، هر دو).
- شناسه ملی (۱۰ رقم حقیقی یا ۱۱ رقم حقوقی) و کد اقتصادی (۱۲ تا ۱۴ رقم).
- تلفن تماس و آدرس.
- گزارش تفصیلی **گردش حساب طرف حساب** با مانده در لحظه (Running Balance).

### ۳. تعریف کالاها و خدمات (Items)
- کد یکتای کالا، عنوان، نوع (کالا / خدمت)، قیمت واحد، درصد مالیات بر ارزش افزوده و موجودی انبار.
- به‌روزرسانی خودکار موجودی انبار هنگام تأیید فاکتور فروش (کسر از موجودی) یا خرید (افزایش موجودی) یا ابطال فاکتور (برگشت موجودی).

### ۴. مدیریت صندوق و حساب‌های بانکی (Accounts)
- تعریف حساب‌های نقدی (صندوق) و حساب‌های بانکی با شماره حساب.
- محاسبه مانده واقعی و لحظه‌ای صندوق و بانک بر اساس مانده اولیه و گردش دریافت‌ها و پرداخت‌ها.

### ۵. ثبت دریافت‌ها و پرداخت‌ها (Payments)
- ثبت دریافت (in) و پرداخت (out) با روش‌های مختلف (نقدی، کارت، حواله بانکی، چک).
- **صدور خودکار سند حسابداری متناظر:**
  - دریافت: بدهکار صندوق/بانک (1101/1102)، بستانکار حساب‌های دریافتنی (1201).
  - پرداخت: بدهکار حساب‌های پرداختنی (2101)، بستانکار صندوق/بانک (1101/1102).

### ۶. صدور فاکتور و صورتحساب الکترونیکی (Invoices)
- صدور فاکتور فروش و خرید با شماره‌گذاری مستقل ترتیبی.
- محاسبه خودکار مبلغ ناخالص، تخفیف، خالص، مالیات و مبلغ کل.
- تولید شناسه یکتای ۲۳ کاراکتری استاندارد سامانه مالیاتی (`generateTaxId`).
- وضعیت‌های استاندارد: «پیش‌نویس» (`draft`)، «آماده ارسال» (`ready`)، «ارسال‌شده» (`sent`)، «تأییدشده» (`confirmed`) و «ردشده» (`rejected`).
- ثبت تاریخچه کامل تغییر وضعیت‌ها (`history`).
- قابلیت صدور فاکتور اصلاحیه (`amend`) با ارجاع به فاکتور اصلی (`refId`).
- قابلیت ابطال فاکتور (`cancel`) همراه با برگشت انبار و صدور سند معکوس خودکار.

### ۷. اسناد حسابداری دوبل تراز (Journal Entries)
- ثبت اسناد حسابداری دوبل بدهکار و بستانکار.
- **کنترل الزامی تراز بودن سند:** در صورتی که مجموع بدهکار با بستانکار برابر نباشد، سرور اجازه ثبت سند را نمی‌دهد.
- تفکیک اسناد دستی از اسناد خودکار صادرشده توسط سیستم.

### ۸. شبیه‌ساز سامانه مالیاتی (Tax Authority Simulator)
- اندپوینت شبیه‌ساز REST API در مسیر `POST /api/tax/invoices`.
- اعتبارسنجی سروری مطابق قوانین مالیاتی (کد اقتصادی، شناسه ملی، جمع ردیف‌ها و...).
- لاگ برداری کامل از درخواست‌ها و پاسخ‌ها و مدت زمان پاسخ در کالکشن `TaxLog`.
- قابلیت تنظیم تاخیر شبکه، ضریب خطا و رد اجباری.

### ۹. گزارش‌های مالی و خروجی اکسل/CSV
- **گزارش فروش** در بازه زمانی مشخص.
- **گزارش خرید و هزینه‌های عملیاتی**.
- **گزارش بدهکاران و بستانکاران** (مانده حساب مشتریان و تأمین‌کنندگان).
- **گزارش سود و زیان ساده** (درآمد - بهای تمام شده - هزینه‌های عملیاتی).
- **تراز آزمایشی و دفتر کل**.
- **دفتر روزنامه**.
- **خروجی اکسل (.xlsx)** و **CSV** برای گزارش‌ها.

### ۱۰. داشبورد مدیریتی
- شاخص‌های کلیدی: مجموع فروش، مجموع هزینه، سود خالص، مطالبات.
- تعداد فاکتورها به تفکیک وضعیت.
- نمودار روند ۶ ماهه درآمد، هزینه و سود.

## 🚀 راهنمای نصب و اجرا

### ۱. نصب وابستگی‌ها
```bash
cd backend-api
npm install
```

### ۲. تنظیمات محیطی (.env)
فایل `.env.example` را به `.env` کپی کنید:
```env
PORT=8000
MONGODB_URI=mongodb://127.0.0.1:27017/invoice_finance_db
JWT_SECRET=super_secret_jwt_key_invoice_finance_system_2026
JWT_EXPIRES_IN=7d
CLIENT_URL=http://localhost:5173
NODE_ENV=development
```

### ۳. درج داده‌های اولیه (Seed Data)
برای درج کاربران اولیه، کالاها، مشتریان، حساب‌ها و فاکتورهای نمونه:
```bash
npm run seed
```

**کاربران پیش‌فرض جهت ورود:**
- **مدیر سیستم:** نام کاربری `admin` / کلمه عبور `admin123`
- **حسابدار:** نام کاربری `acc` / کلمه عبور `acc123`
- **کاربر فروش:** نام کاربری `sales` / کلمه عبور `sales123`

### ۴. اجرای سرور
برای اجرای سرور در حالت توسعه:
```bash
npm run dev
```
سرور بر روی پورت `http://localhost:8000` اجرا خواهد شد.

### ۵. اجرای تست‌های خودکار
```bash
npm test
```

### ۶. مستندات تعاملی Swagger API
پس از اجرای سرور، با مراجعه به آدرس زیر در مرورگر به مستندات Swagger دسترسی خواهید داشت:
```
http://localhost:8000/api-docs
```

## 🐳 اجرا با Docker Compose

```bash
docker-compose up -d
```
این دستور سرور نود و پایگاه داده مونگو دی‌بی را به طور خودکار راه‌اندازی می‌کند.
