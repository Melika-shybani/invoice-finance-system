# راهنمای اجرای داکر و مستندات کامل Swagger API (ویژه اتصال فرانت‌اند)

این پروژه به گونه‌ای داکرایز شده است که توسعه‌دهنده فرانت‌اند بتواند تنها با اجرای **یک دستور داکر**، کل بک‌اند و دیتابیس MongoDB را بالا بیاورد و مستقیماً از طریق رابط گرافیکی **Swagger UI** تمام APIها را تست کرده و در فرانت استفاده کند.

---

## ⚡ نحوه اجرای سریع با داکر (برای فرانت‌اند)

در ریشه پروژه دستور زیر را در ترمینال اجرا کنید:

```bash
docker compose up -d
```
(یا `docker-compose up -d`)

### چه اتفاقی می‌افتد؟
1. پایگاه داده **MongoDB 7.0** به صورت خودکار دانلود و اجرا می‌شود.
2. سرور بک‌اند نودجی‌اس ساخته شده و منتظر سلامت دیتابیس می‌ماند.
3. متغیر `AUTO_SEED=true` فعال است؛ بنابراین کلیه داده‌های اولیه (کاربران پیش‌فرض، کالاها، مشتریان، فاکتورهای نمونه، اسناد افتتاحیه، تنظیمات شرکت) **به صورت خودکار** در پایگاه داده ایجاد می‌شوند!
4. سرور روی پورت **8000** در دسترس قرار می‌گیرد.

---

## 📚 آدرس مستندات تعاملی Swagger UI

پس از اجرای داکر، لینک زیر را در مرورگر خود باز کنید:

👉 **[http://localhost:8000/api-docs](http://localhost:8000/api-docs)**

در صفحه سوگر:
- تمام اندپوینت‌ها با جزئیات کامل، توضیحات فارسی، پارامترها و نمونه بدنه درخواست (JSON Request Body) مشخص شده‌اند.
- می‌توانید با کلیک روی دکمه **Try it out** مستقیماً به سرور درخواست بفرستید و پاسخ واقعی را مشاهده کنید.

---

## 🔑 حساب‌های پیش‌فرض جهت تست در Swagger

| نقش | نام کاربری (Username) | کلمه عبور (Password) | سطح دسترسی |
|---|---|---|---|
| **مدیر سیستم (Admin)** | `admin` | `admin123` | دسترسی کامل به تمام بخش‌ها، کاربران و تنظیمات |
| **حسابدار (Accountant)** | `acc` | `acc123` | دسترسی به اسناد مالی، فاکتورها، دریافت/پرداخت، گزارش‌ها و مالیات |
| **کاربر فروش (Sales)** | `sales` | `sales123` | تعریف مشتریان، کالاها، صدور و مشاهده فاکتورهای فروش |

### نحوه احراز هویت در Swagger:
1. متد `POST /api/auth/login` را باز کرده و با یکی از حساب‌های بالا لاگین کنید.
2. مقدار فیلد `token` را کپی نمایید.
3. در بالای صفحه روی دکمه سبز رنگ **Authorize** کلیک کرده و توکن را وارد کنید (بدون کلمه Bearer).
4. حالا تمام اندپوینت‌های محافظت‌شده را می‌توانید با نقش انتخابی تست فرمایید.

## 🔌 نحوه اتصال فرانت‌اند به این بک‌اند

پروژه فرانت‌اند در `vite.config.ts` پروکسی شده است:
```ts
server: {
  host: '127.0.0.1',
  port: 5173,
  proxy: { '/api': { target: 'http://localhost:8000', changeOrigin: true } },
}
```
کافیست در فرانت‌اند درخواست‌های خود را به مسیرهای `/api/...` با هدر `Authorization: Bearer <token>` ارسال کنید.

## 🛠️ دستورات کمکی داکر

- **مشاهده لاگ‌های زنده بک‌اند:**
  ```bash
  docker compose logs -f backend
  ```
- **توقف کانتینرها:**
  ```bash
  docker compose down
  ```
- **اجرای مجدد با بازنشانی داده‌ها:**
  ```bash
  docker compose down -v
  docker compose up -d
  ```
- **اجرای دستی بدون داکر (حالت محلی):**
  ```bash
  npm run backend:dev
  ```
